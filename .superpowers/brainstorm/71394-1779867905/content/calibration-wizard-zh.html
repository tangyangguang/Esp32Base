校准向导页

用于流量计、投喂克数、自动门端点、电流零点等校准。它不是普通表单，而是“检查条件、录入实测、核对变化、保存结果”的安全流程。

核心：先验证，再保存

一、校准页面要解决什么

避免错误来源必须说明校准依据来自哪条记录、哪次动作或哪个当前读数，不能让用户凭空填参数。
让变化可核对保存前展示旧值、新值、变化幅度和影响范围，避免误填单位导致设备行为异常。
保护设备状态运行中、故障中、传感器不可信、时间无效等状态下，应禁止保存或转入故障处理页。

四、推荐流程

步骤页面职责保存规则
1. 条件检查检查设备是否空闲、传感器是否可信、是否有可用记录或测试动作。不满足时禁止继续，并给出处理入口。
2. 选择依据选择一条记录、一次测试动作、当前零点读数或当前位置。依据必须能追溯，不能只保存裸参数。
3. 输入实测用户输入量杯水量、称重结果、当前位置含义或零点读数。前端提示单位，服务端重新校验范围。
4. 保存前核对展示旧值、新值、变化幅度、影响范围和是否需要强确认。高风险校准进入危险确认页或使用一次性 token。
5. POST 保存保存校准参数，同时写入校准记录或业务事件。使用 POST -> 303 -> GET，刷新不重复保存。

五、不同校准类型的模板

水流量校准依据：最新可校准出水记录。输入：量杯实测值。输出：流量系数或启动补偿。
投喂克数校准依据：测试下料圈数或脉冲。输入：称重结果。输出：每圈克数或每脉冲克数。
自动门端点校准依据：当前位置和低速点动结果。输入：端点含义。输出：关门基准或开门目标，必须强确认。
电流零点校准依据：电机断电/无电流状态下的 ADC 采样。输入：通常无需人工值。输出：零点偏移。
阈值实测记录依据：正常负载和接近堵转的实测电流。输入：备注和确认。输出：建议阈值，不自动启用高风险保护。
高级手动参数只给明确知道单位的人使用，必须展示推荐范围和旧值。优先放 App Config 或高级页。

六、建议定稿规则

校准不是普通配置表单必须围绕“依据、实测、计算、核对、保存”组织页面。
不要远程触发危险动作水龙头 Web 校准只能基于已有本地记录；机械点动类必须显式进入维护/校准模式。
保存前必须显示变化旧值、新值、变化比例和影响范围必须让用户看见。
校准结果可追溯保存时写入校准元数据或业务记录，包括依据、输入、输出和操作者来源。
运行中禁止保存关键校准执行器运行中、状态不可信或传感器异常时，不能保存会影响控制边界的参数。
仍然使用 PRG保存请求必须 POST 后 303 跳转，避免刷新重复写入校准参数。
