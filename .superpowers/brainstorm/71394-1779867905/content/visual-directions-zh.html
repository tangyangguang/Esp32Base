Esp32Base Web Console Kit 视觉方向

目标是同时服务基础库内置页面和正式业务自定义页面，在 ESP32 资源约束下保持专业、清晰、快速。

PC 与手机兼容 无前端框架 样式可裁剪 业务页可复用

本轮确认的边界

  • 支持对象基础库内置页 + 业务项目自定义页，两者共享同一套视觉语言。
  • 核心问题业务页反复手写 CSS，调试成本高，移动端和表单密度容易失控。
  • 设计目标简洁、大方、信息清楚；不是追求装饰效果，也不是做大型 Web 应用。
  • 皮肤更换作为加分项处理，优先通过少量 CSS 变量实现，不引入主题系统复杂度。

推荐判断

不要把它做成“漂亮页面包”。它应该是一个嵌入式设备控制台规范：页面结构、组件 class、默认样式、可选皮肤、静态原型和接入示例一起定义。

A. 极简系统控制台

最接近当前 Esp32Base，字节最省，适合内置页；业务页表达力偏弱。

状态、操作、记录、表单都有固定模式；PC 信息密度好，手机自然单列。

C. 表单与记录优先

重点解决配置页和记录页；适合参数多的设备，但首页操作感不够强。
